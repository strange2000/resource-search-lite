播放 / 下载直链（m3u8、mp4）
关于磁力链接：磁力走 PanSou 实例自己的 magnet 通道（同域名，开了跨域），所以这个页面现在能直接出磁力链。 代价是它只给标题 + 磁力链，没有做种数和体积；要按做种数/清晰度排序，还是让电脑端脚本跑。 apibay / knaben / nyaa 三个站没开 CORS，页面直连不了；想看原站，点上面的 磁力搜索 / apibay 按钮。
为什么这里没有「采集接口」（几千个影视站）：那些站的 JSON 接口一律不带 Access-Control-Allow-Origin（2026-11-14 实测 3 个全是 0 头），浏览器页面调不到。 它们的直链（m3u8）请在终端跑 sh scripts/collect.sh "片名" 拿（脚本内预置 14 个接口，可自行增删）， 拿到后粘到上面「播放 / 下载直链」里就能直接看。
